# Crash Site — Pretoria Backyard

9:16 vertical animated 2D vector scene: a chrome egg-shaped alien star-pod crash-landed in a modest Pretoria suburban backyard, next to a rotary washing line.

## View it

Static site (`index.html`). After GitHub Pages is on:

**https://khumop333-ops.github.io/Lang/**

### Vercel

This sandbox cannot reach Vercel’s API. Deploy in one of these ways:

1. [vercel.com/new](https://vercel.com/new) → Import **khumop333-ops/Lang** → Framework **Other** → Output/root `.` → Deploy.
2. Locally: `npx vercel` in this repo (needs a Vercel login).

`vercel.json` is included for clean URLs.
